iOS Chart Signal Audit

A raw App Store chart jump tells you what climbed, never why. This tool joins stored Apple charts (GET /v1/charts) with batch paid-ad, organic, and US ASO keyword signals (GET /v1/market/signals) from PeekPanda in 2 API calls, classifying every mover while keeping uncollected evidence distinct from zero.

Run on your own chart slice

Runs locally on Node 18+ with zero packages. Uses your PeekPanda API key (stored in PEEKPANDA_API_KEY or ~/.config/peekpanda/api_key) and consumes only 2 API calls per run.

Data honesty: iOS App Store only (no Android coverage). Grossing is a chart position, not dollars. Download and revenue figures are modelled worldwide monthly App Store estimates from PeekPanda, never measured data. Organic matches are suggestions, not proof of ownership. US ASO keyword popularity is directional (0–100), not search volume. Streams that were never collected display as —, never zero.
